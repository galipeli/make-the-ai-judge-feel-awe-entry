The program writes a single 179-character text to `/output/entry.txt` — a text that calms by showing, not telling: snow settling on a far ridge, a mountain that does not hurry, quiet older than any road below.

The text was picked by blind pairwise judging in `judge-lab` (2 rounds, 4 variants, judged only by the competition's printed criteria in order): it won 5 of 6 rounds combined, beating the tide, stars, and evening-light variants.

## Run it

```sh
python3 main.py
```

Python 3.13, standard library only, no network, deterministic — the same text is written on every run.
